# ESP32-S3 ES3C28P Pin Configuration

Based on the LCD Wiki specifications supplied for Dual Motor V2.

## LCD

- GPIO10 CS
- GPIO46 D/C
- GPIO12 SCK
- GPIO11 MOSI
- GPIO13 MISO
- GPIO45 backlight

## Touch

- GPIO16 SDA
- GPIO15 SCL
- GPIO18 reset
- GPIO17 interrupt

Touch is intentionally unused.

## Other resources

- GPIO42 RGB LED
- GPIO38/40/39/41/48/47 microSD
- GPIO1 audio enable
- GPIO4/5/6/7/8 audio I2S
- GPIO0 BOOT
- GPIO9 battery ADC
- GPIO2/3/14/21 expansion
- GPIO43 UART0 RX
- GPIO44 UART0 TX
