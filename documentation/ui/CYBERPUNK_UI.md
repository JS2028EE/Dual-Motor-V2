# Cyberpunk Controller UI

## Orientation

Landscape.

## Style

Dark futuristic console with neon accents, technical panels, strong status indicators, readable telemetry, and minimal clutter.

## Planned sections

- Home / Dashboard
- Connection
- Vehicle Status
- Location
- Manual
- Assistance
- Automation
- Beep
- Lights
- Diagnostics
- Settings

## Controls

Navigation joystick: navigate, press to select, hold to go back.

Driving joystick: driving input, press to brake, hold for emergency stop.
