# V2.1.0 — Wi-Fi Controller Link

## Summary

Dual Motor V2 controller communication has moved from the physical C3↔S3 UART link to a dedicated Wi-Fi network with TCP transport.

## C3

- ESP32-C3 operates as Wi-Fi Station.
- Connects to the S3 AP automatically.
- Sends joystick telemetry approximately every 50 ms.
- Sends navigation/drive button events over TCP.
- Replies to S3 PING messages.
- Automatically retries Wi-Fi and TCP after link loss.

## S3

- ESP32-S3 ES3C28P operates as the Wi-Fi Access Point.
- Creates SSID `DUAL-MOTOR-V2`.
- Uses AP address `192.168.4.1`.
- Runs TCP server on port `4210`.
- Displays Wi-Fi controller connection state.
- Drops stale TCP clients so the C3 can reconnect.
- Keeps the existing Adafruit ILI9341 cyberpunk display UI.

## Protocol

C3 → S3:

```
READY,C3
DEVICE,DUAL_MOTOR_V2_C3
INPUT,navX,navY,driveX,driveY
EVENT,NAV_SELECT
EVENT,NAV_BACK
EVENT,DRIVE_BRAKE
EVENT,DRIVE_ESTOP
PONG,C3
```

S3 → C3:

```
PING
IDENTIFY
```

## Legacy UART

The former UART connection on C3 GPIO20/GPIO21 and S3 GPIO43/GPIO44 is no longer used by the active firmware.
