# V2.2.0 — Live Controller Display + Wi-Fi Reliability

## Summary

V2.2.0 changes the controller from periodic large UI redraws to a live joystick visualization path and hardens the C3↔S3 Wi-Fi/TCP link.

## Live movement

- C3 joystick telemetry: 20 ms / 50 Hz.
- S3 joystick visualization: 30 ms / ~33 Hz.
- Only the local joystick visualization and numeric values are redrawn during normal movement.
- The complete screen is no longer repeatedly redrawn during normal operation.
- This removes the large visible wipe/scan-line effect caused by repeated display-area redraws.

## TCP / Wi-Fi reliability

- S3 and C3 use TCP no-delay mode (setNoDelay(true)).
- S3 uses a non-blocking byte-by-byte packet parser instead of waiting on readStringUntil().
- C3 enables Wi-Fi auto-reconnect.
- C3 immediately drops its TCP client when Wi-Fi association is lost.
- S3 detects stale controller traffic after 2 seconds and closes the stale TCP client.
- Failed TCP writes now cause the S3 client to be stopped so the connection can be rebuilt.

## Validation

Physical validation is still required. Upload the updated C3 and S3 firmware, move the joysticks continuously, and run the controller for several minutes to confirm live response and long-duration Wi-Fi stability.
