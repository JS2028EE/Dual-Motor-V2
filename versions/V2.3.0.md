# V2.3.0 — ESP32 vehicle planning update

Date: October 16, 2026.

This is a documentation/simulation revision, not a working firmware release.

- Replace the damaged C3 dependency and C3/S3 controller-first scope with an ESP32-WROOM-32D vehicle.
- Plan phone/computer control by Wi-Fi or Bluetooth, with automatic obstacle sensing.
- Retain L293D for one drive motor and one steering motor.
- Add GPS, front ultrasonic sensing, buzzer, and two white headlights.
- Document separate motor/electronics supplies, rechargeable-battery options, switching, and pending charging design.
- Evaluate a candidate boost converter and supply capacitors; identify voltage/current/thermal limits.
- Add signal/power block diagrams and a runnable GNU Octave estimate script.
- Record the user's initial Octave plots, assumed results, and lack of electrical/mechanical coupling.
- Preserve earlier controller files and label their documentation as historical.
- Track physical measurements, steering feedback, power checks, firmware, and stop testing as pending.
